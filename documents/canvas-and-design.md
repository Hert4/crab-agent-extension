# Canvas and Design

![Guide](https://img.shields.io/badge/guide-canvas%20%26%20design-7c3aed?style=flat-square)
![Feature](https://img.shields.io/badge/feature-creative%20tools-blue?style=flat-square)

Crab has specialized skills for visual creation, from simple posters to interactive generative art.

## Poster and Graphic Design

Ask Crab to create visual designs and it will generate them as downloadable files or inline previews.

```
Design a minimalist poster for a jazz concert on December 15th
at The Blue Note. Use dark blue and gold colors.
```

```
Create a social media banner for my coffee shop "Bean and Brew"
with a warm, cozy aesthetic
```

```
Make a birthday invitation card for Sarah's 30th birthday party,
theme: tropical vibes
```

### How It Works

| Step | Detail |
|---|---|
| 1 | Crab decides on a visual direction (colors, typography, layout) |
| 2 | Generates HTML and CSS at the right dimensions |
| 3 | Outputs through the document generator as PDF, DOCX, or inline preview |
| 4 | You download or print the result |

### Tips for Better Designs

| Tip | Example |
|---|---|
| Describe the mood | "minimal", "bold", "retro", "elegant" |
| Specify colors | "use navy and coral" |
| Mention the format | "Instagram square", "A4 poster", "Facebook cover" |
| Include all text | Spell out every line you want on the design |

## Generative Art

Crab can create interactive algorithmic art using p5.js.

```
Create a generative art piece with flowing particles in blue and purple
```

```
Make an interactive fractal tree that grows when I click
```

```
Generate a Voronoi diagram with pastel colors that responds to mouse movement
```

| You get | Detail |
|---|---|
| Inline canvas | Interactive HTML canvas in the side panel |
| Regeneration | Re-run with different seeds |
| Export | Download as PNG |
| Supported styles | Particle systems, flow fields, fractals, L-systems, Voronoi, cellular automata |

## Frontend and Web Design

Ask Crab to design UIs and it will produce functional HTML and CSS.

```
Design a landing page for a fitness app called "FitTrack"
with a hero section, features grid, and pricing table
```

```
Create a dark-mode dashboard layout with a sidebar, header,
and 4 stat cards
```

```
Design a login form with email and password fields,
a "Remember me" checkbox, and social login buttons
```

Designs render directly in the side panel as interactive previews. You can view the source code and reuse it in your own projects.

## Working with Canvas Apps

Crab can interact with design tools that render to canvas instead of DOM.

| App | What Crab can do |
|---|---|
| **Figma** | Draw shapes, add text, create frames, use shortcuts (R, T, F) |
| **Miro** | Add sticky notes, draw shapes, create diagrams |
| **Excalidraw** | Draw rectangles, arrows, text, and lines using keyboard shortcuts |
| **Google Docs and Slides** | Type content, format text, insert elements |
| **Canva** | Navigate templates, add elements, edit text |

### Example

```
Open Figma and create a wireframe with a header, sidebar, and main content area
```

```
Go to Excalidraw and draw a flowchart:
Start -> Process Data -> Decision (Yes/No) -> End
```

### How It Works

| Step | Detail |
|---|---|
| Screenshot analysis | Crab reads the UI from images instead of DOM |
| Coordinate-based actions | Clicks toolbar buttons and drags on the canvas using pixel coordinates |
| Smart paste | For complex content (tables, flowcharts, SVGs) Crab generates and pastes directly |

## Charts and Visualizations

Crab can render data charts inline.

```
Create a bar chart showing monthly revenue:
Jan: $12k, Feb: $15k, Mar: $18k, Apr: $14k, May: $22k
```

```
Make a pie chart of browser market share:
Chrome 65%, Safari 18%, Firefox 8%, Edge 5%, Other 4%
```

Charts render as SVG or interactive HTML directly in the chat.
